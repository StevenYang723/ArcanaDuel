# 原创美术素材

最终素材均使用内置 imagegen 工具生成；没有使用 CLI / API key 路径。

- `assets/board.png`：塔罗祭坛背景，按 1440×900 逻辑场景使用。
- `assets/arcana-atlas.png`：21 张塔罗插画图集，顺序为愚者至审判，7 列 × 3 行。`Assets.cs` 保存精确取样范围及每副牌组的主题色。程序运行时对图集取样，独立牌框、文字、资源图标和动画均由 C# 绘制。

最终设计采用高对比黑白剪影、锐利构图与版画纹理，参考 Persona 5 的图形表达；角色、塔罗图案和场景为本项目生成。每副牌组有独立的强调色。写实插画的中间方案没有纳入最终程序。

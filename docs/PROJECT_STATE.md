## 规则基线

- 草案池是大阿尔卡纳 1—20，不含愚者和世界，禁选全局独占。
- 随机先后手：先禁 1、后禁 1、先选 1、后选 2、先禁 1、后禁 1、先选 2、后选 1；实现展开为 10 个单次动作。
- 双方各 3 副选中牌组，再加愚者，一人 20 张牌。世界仅为设计备选，没有实装。
- 道路 0—20，位置 10 开始。自己的伤害向自己视角右边移动，双方棋盘互为镜像；到终点立即获胜，剩余效果停止。
- 每回合 3 费用，回合结束剩余费用变成水晶，水晶上限 3。混合支付时两者按 1:1 抵扣。
- 初始手牌 5，先手首回合不额外抽牌，此后回合开始抽 1。手牌上限 5，新增牌溢出进入弃牌。牌库空则洗弃牌。
- 正在结算的牌不在手牌 / 牌库 / 弃牌中，直到结算结束，不可抽回或回收自己。
- 权杖、圣杯、宝剑、星币共用总上限 13；整张牌结算完后才让拥有者选择弃到上限。
- 共享相反正逆位；通用转位支付 1 点费用或水晶。迷惑使该回合首次通用转位多付 1 点，回合结束过期；卡牌转位不付该附加费。
- 屏障上限 3，抵消伤害，在自己的下回合开始清空；后退不受屏障保护。
- 条件通常在支付固定 / 额外代价且牌离手后记录；“此前”的计数不包含本牌。预知 / 回收 / 挑牌不算效果抽牌，抽牌溢出算效果抽牌。

## 行为与事务

玩家点选费用只更新客户端状态；出牌的 ActionMessage.Crystals 指定固定费用中使用的水晶数，房主仍做权威合法性验证。金额、类型或必需额外代价不符时不提交出牌。选择在已接受的状态变更和操作者切换时清空，临时预览不会清空。

施放先验证固定费用，再配置可选 / 必需的额外代价。准备阶段可取消，确认前不扣资源；确认后支付，锁定该牌施放时正逆位，逐段执行效果。选择只发送给有权选择的人；公开展示和普通动画双方可见。全牌结束后处理资源超限。

Receive 在出牌 / 效果动画结束前保留旧可见状态，期间收到的快照排队；播放后应用新状态。不要直接把状态切到最终结果，否则会破坏双方出牌过程。

正常联机不发送对手手牌或牌库顺序；双人本地测试可以手动打开双方明牌。月蚀临时查看通过只给施法者的 Choice 传递。

## 人机现状

人机不是搜索 / 学习式 AI：随机禁选，C 优先于 B 优先于 A，同级随机；支付优先费用，缺额才用水晶；按手牌数量等条件先判断转位，无合法牌就结束回合。效果选择倾向最大数量和高等级卡，可能错误地优先弃核心牌。预知按 C/B/A 排序全部留顶，超限先弃数量最多的资源。仅有少量魔术师 / 倒吊人的特殊避坑，没有斩杀搜索、连招规划或资源估值。

## 验证方式与已知限制

- 根目录 Test.ps1 -RulesOnly：1538 项规则检查及 35 局完整模拟（历史共 12643 次行动）。
- Test.ps1：还运行真实 WPF 窗口检查，目前 196 项；窗口显示在屏幕外，报告和 PNG / GIF 放到 build/screenshots/。
- 图像不等于全部人工交互覆盖。联机做过本机真实 TCP 和两个窗口镜像演出，未做两台物理电脑实测或真人平衡统计。
- --render-gallery <目录> 为旧的静态渲染入口；需要完整动效与交互检查时优先 --playback-test。
- WPF GIF 编码器可能丢失帧延时；测试输出 GIF 仅作预览，正式演出按运行时动画时钟执行。
- 无公网中继、匹配服务、断线重连、存档、登录或商业支付。
- cards.json 只接受当前内嵌定义，不能随意外改成本或文案；无该文件仍可运行。
- 目前 Windows Framework 编译器语法兼容，不能直接用现代 C# / .NET API。

# 星途对决：v0.2 逐牌复核与修改对照

完整牌面以《阿尔卡纳牌组设计-v0.2》为准。此文记录设计评审，不是对战胜率报告。后续 v1.2 已实装当前可用牌组，运行验证见该版本随附报告。

检查了 22 副牌组的 66 种卡牌、132 个正逆位效果。其中当前可用的 63 种卡牌、126 个效果，修改了 **31 种卡牌的 34 个效果**；世界备选另改 3 个效果。合计保留 95 个效果。固定费用、支付类型、牌组构成均未改变。

## 计算实例

下表假定手牌与水晶有足够空间、没有提前到终点。支付资源指回合费用加水晶，token 单列；“净手牌”包含打出本牌及额外弃牌。

| 效果与使用状态 | 支付资源净变化 | 手牌净变化 | 其他收益或代价 |
|---|---|---|---|
| 魔术师 C 逆位，0 费用、2 水晶 | -2 +3 = +1 | -1 +1 = 0 | 把费用补满到 3 |
| 魔术师 C 逆位，1 费用、2 水晶 | -2 +2 = 0 | 0 | 同一牌面在不同状态下收益不同 |
| 魔术师 C 逆位，3 费用、2 水晶 | -2 +0 = -2 | 0 | 此时不适合打出 |
| 倒吊人 A 逆位，至少 1 费用、0 水晶 | -1 +2 = +1 | -1 +1 = 0 | 后退 1；后退到终点则没有奖励 |
| 倒吊人 C 逆位，至少 2 费用、0 水晶 | -2 +3 = +1 | -1 +2 = +1 | 后退 2 |
| 节制 C 逆位，0 费用、2 水晶 | -2 +1 = -1 | -1 +1 = 0 | 获得两种 token 各 1 |
| 星星 A 逆位，用 1 水晶支付 | -1 +1 = 0 | -1 | 获得 1 圣杯；不是免费循环抽牌 |
| 魔术师 B 逆位，用 2 费用支付、不加权杖 | -2 +1 = -1 | -1 +1 = 0 | 若额外付 1 权杖，则抽 2、净手牌 +1 |
| 命运之轮 B 逆位，主动弃 2 | -2 | -1 -2 +4 = +1 | 获得 1 圣杯；抽牌溢出须另扣 |
| 恶魔 C 逆位，额外弃 1，退款全收下 | -3 +2 = -1 | -1 -1 +2 = 0 | 获得 2 宝剑；并未净赚 2 张手牌 |
| 恶魔 C 正位，3 费用、3 水晶 | -3 -3 = -6 | -1 | 造成 7 点伤害，受屏障影响 |

倒吊人 A 原有 2 水晶时只实际得到 1，支付资源净增变成 0；C 原有 2 水晶时也只得到 1，净变化为 -1。魔术师 B 若用水晶支付而费用原本已满，也不能获得表中的返费收益。上限和当前状态必须参与计算。

- 教皇 A→B→C 的 9 点连招与强化后的 6–7 点核心爆发，是否过早结束 21 格对局。
- 倒吊人后退到终点的即时失败；屏障不可抵消后退。
- 魔术师、节制、死神、星星、倒吊人之间的恢复、回收、重洗循环；循环不能只按单卡看。
- 高塔对称清空在自己/对手水晶各为 0–3 时的收益，以及破坏资源后对手是否仍有合理行动。
- 资源上限 13、手牌上限 5、两种正逆位、先后手对上述结果的影响。

平衡目标是让每个分支有值得使用的局面，避免要求每张牌在任何状态下都赚。对低手牌补满、对称清空等有意保留的时机要求，不用无条件附赠资源抹平。

# 星途对决 · v1.4

双击 **ArcanaDuel.exe** 开始游戏。使用 **C# + WPF / .NET Framework 4.8** 编写，是原生 Windows 桌面程序；场景、21 套塔罗原画、63 种卡牌的 v0.2 规则均已内置，单独复制 exe 也能运行。

建议 Windows 10/11、1280×800 或以上分辨率。F11 最大化，Esc 关闭普通窗口；必需的结算选择须先完成。

## 本次主页与场景更新

- 主页重新设计：金属铭牌入口、三张悬浮塔罗牌、环绕星盘与深色金边布局。
- 主页动效：塔罗牌漂浮和轻微摆动、星环缓慢转动、星尘、光点与柔和光晕，并随鼠标产生轻微视差；入口悬停有高亮和位移反馈。
- 局内动效：烛光明暗变化、上升火星、边缘星尘与缓慢移动的地面符文。动画位于卡牌、资源和按钮下层，不拦截操作。
- 主页右上角“动效：开 / 关”、局内菜单“场景动效：开 / 关”控制场景动画。窗口最小化或场景不可见时停止刷新。设置在当前运行期间保留，重启后默认开启。
- 动态预览：`build/screenshots/home-motion.gif`；新版主页截图为 `18-home.png`，局内截图为 `20-battle-ambience.png`。

## 点选支付与牌面预览

费用支付改为场景内逐枚点选：点击自己的费用或水晶选中，再点同一枚取消；选中的组合决定下一次出牌的固定费用。新增局内正逆位预览，悬停按 R，或单击 / 右键手牌打开大图切换效果，均不改变真实局面。

卡牌左上角显示支付类型和总点数。徽章颜色与所属卡牌一致，仅以形状区分支付类型：圆形仅消耗回合费用，菱形仅消耗水晶；上尖下圆的竖向水滴形表示通用费用，可任选资源或混合支付。徽章内数字始终是所需总点数。手牌、悬停大图、图鉴与出牌动画统一使用。

## 已实装内容

- 当前可用的 21 副牌组（含自动加入的愚者）、63 种卡牌、126 个正逆位效果，费用与文案按 v0.2。世界仍不进入禁选池。
- 权杖、圣杯、宝剑、星币的获得、消耗、调色和超限弃置。
- 屏障、迷惑、费用恢复、水晶获得、卡牌转位、后退和即时终点判定。
- 预知、公开展示、牌顶挑选、主动弃牌、置底排序、弃牌回收、临时查看对手手牌。
- 同牌组仪式、不同牌组接力、低手牌、伤害/抽牌/转位记录、弃牌区组成等条件。
- 精确混合支付、额外代价选择、对手选择失去资源、分阶段结算与双方出牌演出。

## 一个人操作双方

选择「双人测试」。禁选可逐步操作，也可点击「随机完成剩余禁选」。战斗中会自动切换到当前回合玩家；高塔要求对手选择失去的资源时，会临时切到对手，完成选择后切回施法者。

左上 **⇄** 手动切换视角，**◎ / ◉** 切换双方明牌。也可选择「单人练习」，与规则 AI 对战。

## 操作

- 手牌横向排列，悬停查看大图；按 R 查看另一牌面，再按 R 切回。单击或右键手牌打开固定大图，可点击“预览正位 / 逆位”。预览不花资源，不改变实际正逆位；出牌仍按实际状态结算。弃牌区的卡牌也可点击预览。
- **卡牌左上角显示支付类型和总点数：圆形＝仅回合费用，菱形＝仅法力水晶，水滴形＝可任选或混合支付。颜色与卡牌相同，不表示支付类型。** 例如水滴徽章内为 2，可支付 2 费用、2 水晶或各 1 点。
- 点击右下方自己的费用或水晶逐枚选中，再点取消；勾选和描边表示已选，计数为“已选 / 当前拥有”。圆章数字显示已选总点数，点击可清空。先选中合计等于牌费且类型合法的组合，再拖牌到场中施放。例如选 2 费用 + 1 水晶，3 费通用牌就按此组合直接支付，不弹支付分配窗口。选多、选少、类型不符均不出牌、不扣费；拖出施法区松开也不支付。
- 固定费用的选择不包含额外代价；恶魔核心仍额外消耗支付后剩余水晶。有可选额外代价时，先选择再确认；此阶段可取消，尚未支付资源。施放后，预知、回收、资源获得等选择必须完成。
- 左下日月星盘：先点选合计 1 点费用或水晶，再点击星盘转位。受到迷惑时，首次通用转位先选合计 2 点，可混合支付。卡牌转位不支付该附加费用。
- 右侧 **▶** 结束回合。小阿尔卡纳、屏障与迷惑使用场景圆章显示，悬停查看说明。
- 右侧实体牌堆显示牌库和弃牌区张数；点击弃牌堆查看。
- 左上 **☰** 打开规则、记录、声音、图鉴及退出选项。图鉴可查看每副牌组的 A/B/C 与两个分支；手牌显示当前生效分支，悬停大图默认显示该分支，可按 R 临时查看另一面。

### 预知与排序

依次点击牌，序号表示新的顺序；再次点击可撤回。预知窗口再选择“前几张留在牌顶”：前 N 张留在牌顶，其余按已选顺序放到牌库底。选择 0 表示全部置底。纯置底排序不需要设置顶部数量。

回收不同大阿尔卡纳的牌时，所选牌必须来自不同牌组；无效组合会提示并重新显示选择窗口。超出手牌上限的新牌仍进入弃牌区。

费用选择属于当前本地操作者，预览不会清空选择；成功操作、进入结算选择、结束回合或切换操作者时会清空。对手回合、出牌演出和结算选择期间不能点选资源。

## 两人联机

1. 两台电脑运行本版本 exe。
2. 房主选择「创建联机房间」，开始等待，将显示的 IPv4 与六位口令告诉另一位玩家。
3. 另一方选择「加入联机房间」，输入房主 IP、口令和称呼。
4. 连接后随机先手并进入禁选。同一台电脑开两个 exe，可用 `127.0.0.1` 连接。

使用 TCP 27841、房主权威校验。房主需允许专用网络防火墙连接。异地联机需要双方已有的 VPN/虚拟局域网或可达公网 IP 与端口转发；没有公共中继服务。断线会暂停并提示，目前不支持重连或存档。

使用协议 3，v1.4 与 v1.2 的规则和联机协议相同；建议双方使用新版以统一牌面。对手手牌、牌库顺序和私有选择不会常规发送；预知只发给查看者，月蚀临时授权查看，公开展示牌双方都能看到。双方先播放出牌与效果，再更新可见局面。

## 核心规则

道路 **21 格**，中央第 11 格出发，双方各距终点 **10 格**。伤害向自己右方推进；双方视角镜像。后退会向对手终点移动，不受屏障保护；任何移动到终点立即结束，不再领取后续奖励。

20 副可禁选牌组不含愚者、世界。顺序：先禁 1、后禁 1、先选 1、后选 2、先禁 1、后禁 1、先选 2、后选 1。每人选择 3 副，再加入愚者；各副 A×2/B×2/C×1，共 20 张。

每回合 3 费用，未使用部分在回合结束转为水晶，水晶上限 3。初始手牌 5；先手首回合不额外抽牌，之后回合开始抽 1。手牌上限 5；牌库空时重洗弃牌。正在结算的牌不属于手牌、牌库或弃牌区，不能抽回或回收自己。

小阿尔卡纳合计上限 13，整张牌结算后由拥有者弃置超限部分。屏障上限 3，在自己的下回合开始时清除。迷惑不叠加，影响下回合首次通用转位，回合结束失效。

## 配置与源码

`cards.json` 是随附的 63 张牌面清单，程序会校验它与内置规则一致；不要继续使用旧版的全局 A/B/C 调费方式。修改规则应同时修改源码中的卡牌定义、效果逻辑并重新构建，以避免文案与效果不符。

`src/` 提供全部 C# 源码、原始素材和 `Build.ps1`。在 PowerShell 中运行构建脚本即可，使用系统 .NET Framework 编译器，不依赖浏览器、Node.js 或外部游戏引擎。脚本会在 `src/bin/` 生成 exe。`src/ART_NOTES.md` 保留原画来源和生成说明。

`卡牌设计-v0.2.md` 为完整卡牌效果参考；世界部分仅为扩展备选。

## 验证范围

`docs/rules-v1.2.txt` 为规则与本机 TCP 联机报告；`docs/presentation-v1.4.txt` 为实际 WPF 窗口的输入、支付、选择、演出、镜像棋盘、图鉴及全部牌面文字适配检查。规则测试包含每个正逆位效果的基础与条件场景、数值对照、资源与卡牌守恒，以及完整模拟对战。

联机自动验证在同一台电脑的 TCP 两端完成，尚未在两台独立电脑之间实测，也不代表真人对战平衡已经验证。

复跑：`ArcanaDuel.exe --test`；界面检查：`ArcanaDuel.exe --playback-test <截图输出目录>`。
